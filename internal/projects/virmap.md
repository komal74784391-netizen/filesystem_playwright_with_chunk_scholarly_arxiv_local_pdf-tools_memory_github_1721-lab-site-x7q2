# Project Virmap — boreal moss microbiome

Status: completed · Lead: Ida Kaasa

## What we do

Virmap characterised viral and microbial diversity in boreal mosses and
built the reference material still used for classification.

## Methods and software in use

- Profile HMM searches with HMMER against Pfam.
- Biosynthetic gene cluster detection with antiSMASH.
- Community statistics and ordination in R (vegan, phyloseq).
- Reproducible reports generated with Quarto.
